One-time Salesforce Setup

You need a Salesforce Connected App to authorize this page. Ask your Salesforce admin, or do it yourself if you have admin access.

Steps (takes about 5 minutes):
  1. In Salesforce: Setup → App Manager → New Connected App
  2. Name it anything. Check Enable OAuth Settings
  3. Callback URL: https://atroggio-art.github.io/account-sites/command-center.html
  4. OAuth Scopes: add Access and manage your data (api) and Perform requests anytime (refresh_token)
  5. Save. Copy the Consumer Key (Client ID)
  6. Setup → CORS → Add https://atroggio-art.github.io
  7. Paste the Consumer Key and your org URL into the form
